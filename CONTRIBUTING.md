# Contributing to agent-memgc

Thank you for your interest in contributing to `agent-memgc`! We welcome contributions, bug reports, and pull requests from developers and systems engineers.

## Development Workflow

1. Fork and clone the repository.
2. Build the project using `cargo build`.
3. Run tests using `cargo test`.
4. Ensure all changes maintain strict zero-allocation performance principles where possible.
5. Format code with `cargo fmt` before submitting pull requests.

## Code of Conduct

This project adheres to standard open-source community standards. Please review our [Code of Conduct](CODE_OF_CONDUCT.md).
